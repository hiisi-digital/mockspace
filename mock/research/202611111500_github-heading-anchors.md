# GitHub heading anchors

A reference to a heading is the heading's anchor, folded, so `forge_slug` has to give what GitHub
gives. GitHub's own renderer is not published; the slugger it is documented to follow is
`github-slugger` (https://github.com/Flet/github-slugger, `index.js`, `regex.js` and
`script/generate-regex.js` on `master`, fetched 2026-11-11).

## The algorithm

The whole of `slug(value)` in `index.js`:

```js
if (!maintainCase) value = value.toLowerCase()
return value.replace(regex, '').replace(/ /g, '-')
```

`regex.js` lists every character to delete, and it is generated by `script/generate-regex.js` in
the same repository from the Unicode 13.0.0 data. The generator adds these general categories to
the set it deletes, in its own words:

```js
'Other_Number',
'Close_Punctuation', 'Final_Punctuation', 'Initial_Punctuation', 'Open_Punctuation',
'Other_Punctuation', 'Dash_Punctuation',
'Symbol', 'Control', 'Private_Use', 'Format', 'Unassigned',
'Separator'
```

and then takes back out of it every character with the `Alphabetic` property ("Some overlap
between letters and Other Symbol"), the space and the hyphen. What it keeps is therefore anything
alphabetic (the letters, the letter numbers, and the marks and symbols Unicode calls alphabetic,
such as a circled letter), the other marks, the decimal digits, the connector punctuation (`_` and
its kin such as `‿`), the space and the hyphen. An other number such as a superscript two is
deleted. The generated regex opens with `[\0-\x1F!-,\.\/:-@\[-\^`\{-\xA9 ...`, so a tab is deleted
and a no-break space (0xA0), a separator, is deleted too.

So, in order: lowercase, delete, then every remaining ordinary space becomes one hyphen.

## What follows

- A run of spaces is a run of hyphens: `a  b` is `a--b`. There is no collapsing.
- Nothing is trimmed: a trailing `-` or a trailing space survives, so `Foo -` is `foo--`.
- A hyphen between spaces stays: `a - b` is `a---b`.
- A tab is deleted, not a separator: a tab between two words joins them.
- `C++ & Rust` is `c--rust`: the punctuation goes, both spaces stay.

## Not covered

`forge_slug` reads the classes from the Unicode version of the Rust standard library and the
`regex` crate, not 13.0.0, so a character assigned after 13.0.0 can be kept here where the slugger
deletes it as unassigned. The standard's names are ASCII, so a heading holding one folds to no
name either way. Duplicate headings get a `-1` suffix from the stateful slugger; a reference names the first.
