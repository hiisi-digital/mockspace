# Topic: split the four modules over 1000 lines into module trees

**Date:** 2026-07-19
**Phase:** TOPIC
**Scope:** `src/render_agent.rs` (2922), `src/bootstrap.rs` (2590), `src/entry.rs` (1386),
`src/design_round.rs` (1110). Each becomes a `mod.rs` plus concern submodules, every file under 500 lines.
**Motivation:** op, 2026-07-19. `file-size-limit.md` names 500 lines the smell; these four are far past it,
and the gate/launcher work grew two of them. Pure behaviour-preserving movement into module trees along
natural seams.

## Method

Each module is converted from `src/<name>.rs` to `src/<name>/mod.rs` plus submodule files grouped by
concern. The externally-used items (only `bootstrap::bootstrap_from_buildscript` crosses the crate boundary;
the rest are crate-internal) stay reachable: the public entry and shared consts remain in `mod.rs`, private
helpers move to submodules as `pub(crate)` and are re-exported via `pub(crate) use <sub>::*;`, so
cross-submodule calls resolve through `use super::*`. Test modules move to a `tests` submodule (or their
concern file) with `super::` rewritten to the absolute module path.

Behaviour is unchanged: no logic edits, only relocation. Verified per file by (1) every original top-level
item appearing exactly once across the split, (2) `cargo check` green, (3) `cargo test` green with the same
test count.

## The seams

- **design_round**: `mod.rs` keeps `SubcmdOpts` + the six `cmd_*` commands; `archive.rs`, `files.rs`
  (rename + legacy-filename), `git.rs` (commit/git helpers), `tests.rs`.
- **entry**: `mod.rs` keeps `run`/`run_inner` dispatch; submodules for the subcommand handlers, the
  mock-dir resolution, the check/clean/nuke helpers, and tests.
- **bootstrap**: `mod.rs` keeps `bootstrap_from_buildscript` + shared consts/helpers; submodules
  `proxy`, `remote`, `lints`, `hooks`, `durable`, `launcher`, `alias`, `activate`, `repair`, `gitignore`,
  `tests`.
- **render_agent**: `mod.rs` keeps the top-level `render_agent` entry; submodules for the builtin hooks,
  the settings generation, the helpers, and tests.

Exact groupings are recorded in the src changelist.
