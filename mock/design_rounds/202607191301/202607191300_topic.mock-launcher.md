# Topic: a thin mock / cargo-mock launcher on PATH

**Date:** 2026-07-19
**Phase:** TOPIC
**Scope:** `src/bootstrap.rs`. A new `ensure_launcher` step that installs a POSIX-sh launcher into the cargo
bin dir. Additive: the existing `.cargo/config.toml` aliases stay as the floor.
**Motivation:** op, 2026-07-19. Wants `mock foo` as a short form, and a cwd-independent entry that discovers the
proxy from known locations rather than a fragile relative manifest path.

## Decision

Install a tiny shell script to `$CARGO_HOME/bin` (default `$HOME/.cargo/bin`) as two names:

- `mock`: the short form. Runs from any cwd.
- `cargo-mock`: cargo`s external-subcommand convention, so `cargo mock ...` finds it on PATH.

The script is generated by the bootstrap, idempotent by fingerprint, executable, and installed only when the
cargo bin dir exists (skip silently otherwise; the `.cargo/config.toml` alias remains the floor). It:

1. resolves the repo root by walking up from cwd for `.git` (or `mockspace.toml`).
2. reads the mock dir via `git config --local mockspace.mockdir` (default `mock`).
3. execs `cargo run --manifest-path "$root/target/mockspace-proxy/Cargo.toml" -- --dir "$root/$mockdir" "$@"`,
   all absolute, so cwd never matters.
4. self-heals a cleaned proxy with `cargo check --locked` in the mock dir, then retries; errors clearly if it
   cannot.

### Why additive, not a replacement

Cargo resolves a `.cargo/config.toml` alias before an external `cargo-mock` on PATH, so keeping the alias
means `cargo mock` still goes through it (covered from the repo root and, since the mock-dir round, from the
mock dir). `mock` becomes the cwd-independent form. Nothing regresses. Dropping the alias to make `cargo mock`
itself fully cwd-independent would bet that entry point on `$CARGO_HOME/bin` being on PATH; that is the
separate, larger launcher decision recorded in `mock/research/202607191140_launcher-vs-buildrs.md`, which also
removes the build.rs bootstrap. This round is the additive first step.

## Folded-in review fix (PR #266, low)

`ensure_mock_local_alias` (and the pre-existing `ensure_cargo_alias`) match an alias line by
`starts_with("mock")`, which would clobber a differently-named key such as `mockfoo`. Tighten both to match
the exact `mock` key (the token before `=`).

## Not in scope

Removing the alias or the build.rs bootstrap (the research-note launcher). Installing to a non-cargo PATH dir.
