## Incident addendum: the sccache amplifier (op-identified)

`~/.cargo/config.toml` sets `rustc-wrapper = "sccache"` globally, and the sccache cache at
`~/Library/Caches/Mozilla.sccache` was found carrying 457 root-owned entries. A single sudo-run build with
no server alive auto-spawns the sccache server as root; every ordinary user build then routes through that
server for its lifetime and receives root-owned compile outputs wherever it builds. This explains the
multi-repo weekday clusters without repeated sudo use. Machine-side remediation (op's, outside this round):
purge the root-owned cache shards, `sccache --stop-server` for a clean user-owned respawn, and consider
dropping `HOME` from sudoers `env_keep`. Guard B in this round prevents mockspace's bootstrap from
installing under sudo; it cannot and does not police sccache.
