## CHANGE: fn `token_scan_core` + `no_std_evaluate` ADDED

File: `mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs`

`token_scan_core(nam, config_bytes, config_len, out_entries, out_capacity, out_len, rule_id)` is the shared evaluator: decodes the variable config blob, walks NAM v1.x entries, scans each file per token outside strings and comments, and emits one diagnostic per match carrying `rule_id`. `no_std_evaluate` is the thin `extern "C"` vtable wrapper baking `rule_id = b"no-std"`. Overflow + null-arg contract matches the other evaluators.

Verification: `grep "fn token_scan_core" mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs` returns one match; `grep "fn no_std_evaluate" mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs` returns one match.

## CHANGE: fn `decode_token_config` ADDED (length-prefixed blob decoder)

File: `mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs`

Decodes the blob into `TokenScanFlags` plus a fixed `[(offset, len); MAX_TOKENS]` table. Returns `None` on any malformation (`MAX_TOKENS = 32`).

Verification: `grep "fn decode_token_config" mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs` returns one match.

## CHANGE: strip-span detector ADDED (`scan_one_token`, `strip_span_at`, plus span helpers)

File: `mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs`

`scan_one_token` walks the source skipping strip-spans and emits each match offset. `strip_span_at` ports `mockspace_rs::strip` span detection; helpers `find_line_end`, `find_block_comment_end`, `find_string_end`, `match_raw_string_end` port the corresponding strip internals. `token_boundary_ok` ports the `scan_token` word-boundary rule; `make_token_diagnostic` builds the per-match diagnostic.

Verification: `grep "fn scan_one_token" mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs` returns one match; `grep "fn strip_span_at" mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs` returns one match.
