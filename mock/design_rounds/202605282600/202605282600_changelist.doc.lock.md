# Doc changelist: bucket-2 ast-type-position cdylib evaluator

**Date:** 2026-05-28
**Phase:** DOC (locked)
**Round:** 202605282600

The `mockspace-builtin-lints` crate is its own cargo workspace, excluded from the tool's `mock/` doc tree, so it ships no `DESIGN.md.tmpl` under `mock/crates/`. This doc changelist is the design narrative for the source slice; there are no `*.md.tmpl` edits.

## Design

The cdylib already ports `file-metric` (line/byte/item-count), `token-scan` (TODO/marker scanning), and the bucket-2 item-count walk. This slice adds `ast-type-position`, the type-position primitive.

### Evaluator shape

`ast_type_position_evaluate` follows the established v2 host-owned-buffer contract used by every other evaluator in the crate: null `out_entries` / `out_len` give `InvalidArg`; an empty config is a no-op (`out_len = 0`, `Ok`); on overflow the first `out_capacity` diagnostics are written, `*out_len` is set to the would-have count, and `AbiStatus::Internal` is returned, else `Ok`.

### Config wire format

A variable-length blob mirroring the existing `decode_token_config` style, decoded defensively (bounds-checked, panic-free, no alloc): `[visibility: u8][positions: u8][forbidden_count: u32]` then `forbidden_count` entries of `[len: u32][bytes...]`. `visibility` is `0 = Any`, non-zero = `Public`. `positions` is a bitset over StructField (1), EnumVariantField (2), FnParam (4). Forbidden type names are stored as `(offset, len)` pairs into the config blob, capped at 32; the evaluator compares each type leaf's source-span bytes against them.

### Walk

For every `TYPE_IDENTIFIER` / `PRIMITIVE_TYPE` leaf, the nearest enclosing position container (FIELD_DECLARATION / PARAMETER / ENUM_VARIANT) is found by a parent-index walk. The nearest rule de-duplicates nested containers, so a field-type leaf inside an enum variant is counted once against the FIELD_DECLARATION. The container's position bit must be selected; the enclosing item's visibility (read via the existing `node_is_public`, walking up to the nearest item-kind node) must match the filter; the leaf's source-span text must equal a forbidden entry. A match emits one diagnostic spanned to the leaf's byte range.

### Position coverage boundary

StructField, EnumVariantField, FnParam land. FnReturn and TypeAliasBody are deferred (no v1.2.0 position-kind node expresses them); they await a later NAM bump.
