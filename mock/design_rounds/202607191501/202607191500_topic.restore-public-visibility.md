# Topic: restore public visibility narrowed by the module split

**Date:** 2026-07-19
**Phase:** TOPIC
**Scope:** `src/bootstrap/mod.rs`. Re-export four functions publicly. PR #268 review fix.

## Finding

The split moved `activate`, `deactivate`, `is_active` (to `activate.rs`) and `ensure_mockspace_current` (to
`remote.rs`). They were externally `pub` under `pub mod bootstrap` on dev, reachable as
`mockspace::bootstrap::activate`. The split re-exports them only via `pub(crate) use`, so the external surface
shrank. No consumer calls them today (bins use `mockspace::run`), so nothing breaks, but it contradicts the
round`s pure-relocation claim.

## Decision

Re-export the four by name at `pub` from `bootstrap/mod.rs`, alongside the existing `pub(crate) use`
globs: `pub use activate::{activate, deactivate, is_active};` and `pub use remote::ensure_mockspace_current;`.
Restores the pre-split external API exactly. The `pub(crate) use` globs stay for the crate-internal helpers.

## Not in scope

The blanket `#![allow(unused_imports)]` on submodules (a documented tradeoff of the glob-based split,
accepted in review). The launcher-replaces-bootstrap redesign (separate, larger).
