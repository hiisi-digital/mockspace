## CHANGE: fn `item_metric` + classification + visibility helpers ADDED

File: `mockspace/mock/crates/mockspace-builtin-lints/src/lib.rs`

`item_metric` walks `nam_file_nodes`: finds the SOURCE_FILE root, counts its direct item-kind children (`is_item_kind`), and counts public ones (`is_pub_item_kind` + `node_is_public`, which reads the child VISIBILITY_MODIFIER source span for exactly `pub`). Returns 0 when no tree is serialised. `is_item_kind` / `is_pub_item_kind` mirror `file_metric`'s item breadth and `is_pub_item` set; `node_is_public` navigates children by parent-index scan (D2) and reads source byte spans (D3).
