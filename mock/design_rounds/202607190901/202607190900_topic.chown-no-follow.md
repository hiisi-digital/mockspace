# Topic: the sudo ownership repair must not follow symlinks

**Date:** 2026-07-19
**Phase:** TOPIC
**Scope:** `chown_tree` and `repair_ownership` in `src/bootstrap.rs`, shipped in round `202607190816`.
**Trigger:** automated commit security review, HIGH, on the round-two commit.

## The defect

`chown_tree` runs as root during the sudo ownership repair and calls
`std::os::unix::fs::chown`, which dereferences symlinks. A symlink planted inside a bootstrap output
directory (`.cargo`, `target/mockspace-proxy`, `mock/target/hooks`) between creation and repair would
redirect the chown onto its target, handing an arbitrary root-owned file to the invoking user. The
directory-descent guard used `path.is_dir()` and `!path.is_symlink()`, but the `chown` on the entry itself
still followed. Practical odds are low (local attacker racing a symlink into a freshly created
bootstrap-owned tree during a sudo build), the class is high because it executes as root.

## Decision

No-follow throughout the repair:

Replace every `chown` in `chown_tree` and `repair_ownership` with `lchown`
(`std::os::unix::fs::lchown`), which chowns the link itself and never dereferences.

Drive the descent decision from `std::fs::symlink_metadata` rather than `path.is_dir()`. A symlink's
`symlink_metadata` reports the link, not its target, so `is_dir()` on it is false and the walk never
descends through a symlink.

Net effect: a symlink encountered anywhere in the tree is chowned in place as a symlink (harmless) and never
followed, so the repair cannot touch a file outside the bootstrap's own output roots. This is the review's
"at minimum" remediation. The stronger openat/O_NOFOLLOW/fchown TOCTOU hardening is not adopted: it needs
raw fd plumbing for a defense against a race on a directory the bootstrap created microseconds earlier and
owns, which is disproportionate to the residual risk.

## Tests

Add a case to the existing repair-traversal test: plant a symlink inside the tree pointing at an external
file, run the repair as the caller's own uid, and assert the external file's ownership and the symlink's
own target are untouched (the link was not followed).
