# The crates the gates found undesigned

The second half of round `202611240329`, whose topic, `202611240329/202611240327_topic.the-repository-runs-its-own-gates.md`, settles both halves. That round renamed what the commit gate refused; this one writes the design documents the build and push gates asked for, which could not be committed before the renames were.

## Types no design names

Twenty types in `mockspace-builtin-lints`, `mockspace-refnames` and `mockspace-test-fixtures` are named by no design document. Each crate gets a `DESIGN.md.tmpl` that says what it is for and names each of its types, written from the crate's own source and the rounds that made it.

## A design describing a crate that was replaced

`mockspace-config`'s documents describe the v1 render-context `Config` and the `IntoMockspaceConfig` trait, which the v2 schema of spec §46 replaced in the crate. The spec is the design the crate is built to, so the documents are rewritten to it. `mockspace-template`'s three documents named the trait as the way another tool reaches its context; its own context model is any serialisable value, so those lines say that instead.
