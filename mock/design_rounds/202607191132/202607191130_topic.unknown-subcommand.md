# Topic: an unknown cargo mock subcommand must not silently run the default

**Date:** 2026-07-19
**Phase:** TOPIC
**Scope:** `src/entry.rs` subcommand dispatch.
**Motivation:** op, 2026-07-19. `cargo mock foo`, where `foo` is not a known subcommand, currently falls
through to the default full regeneration, which is slow and does unwanted work. A mistyped subcommand should
be caught and corrected, not silently executed as something else.

## Current state, verified

The dispatch (`src/entry.rs:90`) matches `positional_args.first()` against the known subcommands, and the
catch-all arm is `_ => {} // Not a subcommand, continue to flags.` (near `:178`), which lets any unrecognised
first positional fall through to the default lint/regen path. Two facts make a naive fix wrong:

1. The `cargo mock` alias prepends `--dir mock`, so the subcommand is never `args[1]`; it is the first
   positional after `--dir` and its value. `positional_args` already strips `--dir <val>`.
2. `positional_args` does NOT strip `--scope <val>`, so `cargo mock --lint-only --scope arvo` leaves `arvo`
   as the first positional. Today that is harmlessly ignored by the catch-all; if the catch-all became a hard
   error, every `--scope <crate>` hook invocation would break.

## Decision

Two changes:

1. Strip `--scope <val>` when building `positional_args`, the same way `--dir <val>` is stripped, so a scope
   value is never mistaken for a subcommand. (Both are the only value-taking flags in the surface.)
2. Replace the catch-all `_ => {}` with an unknown-subcommand handler that prints the available subcommands
   and a `did you mean` suggestion (nearest known subcommand by edit distance, suggested when close), then
   returns a non-zero exit. Bare `cargo mock` (no positional after `--dir mock` is stripped) is unaffected and
   still runs the default regeneration.

The known-subcommand list becomes a single const slice, used both for the match-completeness and for the
suggestion and help output, so the three cannot drift apart.

## Not in scope

Restructuring the flag parser into clap. The surface is small; a positional check plus one value-flag skip is
proportional. A larger parser rewrite is its own decision.
