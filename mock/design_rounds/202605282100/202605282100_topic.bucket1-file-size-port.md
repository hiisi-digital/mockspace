# Why this round exists

#614 landed the no-todo cdylib, which carried no config. file-size is the first lint with real config (a metric + a threshold), so this slice settles the config-bytes wire format for a no_std / no_alloc cdylib that cannot parse TOML. It also resolves a memo-vs-catalog drift: the #214 priority memo named "file-size, actionable-errors, no-bare-pub" as bucket 1, but the catalog tells a different story (see the DOC CL).

# What lands

A `file-size` provider (`mockspace-builtin.lint.file-size.v2`) on the existing cdylib: a `#[repr(C)] FileSizeConfig` carried via `lint_config_bytes`, a `file_size_evaluate` counting lines per a configured metric, and the line-counting core with `str::lines()` semantics. One diagnostic per file whose count crosses the threshold. Unit tests cover the line-count parity, the metrics, the threshold inclusive/exclusive boundary, the empty/malformed config paths, and the multi-entry walk.
