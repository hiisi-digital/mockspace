## D1: thin per-lint wrappers over the shared core

The four remaining token-scan lints (no-alloc, no-dyn-dispatch, no-runtime-registration, no-runtime-spawn) reuse `token_scan_core` unchanged. Each is exactly a `(provider id, rule id)` pair: the tokens, word-boundary flag, and strip flags all arrive at runtime in the config blob (host-supplied from the preset TOML), so the cdylib bakes only the rule id. This honours task #610 R4 (per-lint provider ids for descriptor-time enumeration) while keeping one shared evaluator.

A `token_scan_lint!` macro generates the four (provider const, `extern "C"` evaluate wrapper, vtable static, `ProviderExport` marker) tuples so the only per-lint differences (provider id string, rule id) are stated once each and a copy-paste rule-id drift is impossible. The existing no-todo / file-size / no-std providers stay hand-written; the macro covers only the homogeneous token-scan tail.
