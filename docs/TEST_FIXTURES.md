# mockspace-test-fixtures

A builder for the repositories the v2 integration and end-to-end tests run against. Each test needs a fresh directory set up the same few ways: the bootstrap installed, a `mock/` directory, a `lints.toml`, a cargo workspace of crates carrying source that a lint should or should not find something in. The builder holds those steps once, so a test says which it wants and gets the directory.

A test dependency only. Nothing here reaches a published crate.

## What this crate provides

| Item | Role |
|---|---|
| `MockspaceFixture` | A built fixture: owns its temporary directory, which is deleted with it, and hands out its path. `MockspaceFixture::new()` starts a builder. |
| `MockspaceFixtureBuilder` | What the fixture will hold, each step opt-in: `with_install` runs the bootstrap install, `with_mock_dir` makes `mock/` alone, `with_lints_toml` writes a `lints.toml`, `with_rust_crate` adds a workspace member with the given `src/lib.rs`. `build` makes the directory. |
| `RustCrateSpec` | One crate `with_rust_crate` was given, its name and its source, written out by `build` into `crates/<name>/` and listed as a member of the root `Cargo.toml`. Private to the builder. |
| `FixtureError` | What `build` fails with: the temporary directory could not be made, a write failed, or the bootstrap install refused. Each carries the error it came from. |

## What it refuses

A crate name outside `[a-zA-Z0-9_-]+` panics in `with_rust_crate`, since the name is written unquoted into a manifest and into a path.
